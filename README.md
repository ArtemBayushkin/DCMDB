# DCMDB — DCM Meeting Minutes Manager

Настольное приложение на **PyQt6** для управления протоколами DCM (Design Change Management), срочными вопросами (CQ) и связанной документацией. Приложение работает поверх базы данных **Microsoft Access (.accdb)** через `pyodbc` и предназначено для внутреннего использования командой (~20 пользователей).

> Статус: активная разработка. Готовится к раскатке на пользователей через сетевую шару.

---

## 📋 Возможности

- **Работа с DCM/CQ базой** — просмотр, фильтрация, сортировка и редактирование записей напрямую из Access-базы.
- **Гибкая модель разрешений** — редактируемые колонки задаются по ролям (`default` / `admin` / `tech`) через настройки, только что-то `read-only` (например, PK) заблокировано на уровне модели.
- **Read-only с возможностью копирования** — заблокированные для редактирования ячейки всё равно можно выделить и скопировать текст (`ReadOnlyTextDelegate`).
- **Гиперссылки и вложения** — клик по ячейке с гиперссылкой (поля `Appendix` / `Приложение`) открывает связанный файл; при отсутствии файла — понятное предупреждение с «сырым» и очищенным путём.
- **Защита от битых данных** — построчный `try/except` при чтении курсора спасает от `UnicodeDecodeError` на повреждённых hyperlink-полях Access.
- **Чекбоксы, даты, текст** — типизированная модель данных (`PandasModel`) с поддержкой `checkbox`, `date_short`, `hyperlink`, `text` колонок.
- **Отложенное сохранение (bulk update)** — изменения в таблице копятся локально и сохраняются пачкой в Access одним запросом на пользователя, с логированием и защитой от ложных срабатываний (сравнение old/new перед записью в change-лог).
- **Импорт из Excel** — загрузка входящих CQ/DCM форм из `.xlsx` с сопоставлением колонок (`CQ_COLUMN_MAP`, `DCM_COLUMN_MAP`).
- **Идентификация пользователя** — автоматическое определение текущего пользователя по логину Windows и сверка с базой сотрудников (права администратора, ФИО и т.д.).
- **Вкладки-модули**: Главная, Администрирование, Все вопросы в работе, Команда, Проверка перевода, Настройки — с единым реестром (`TAB_REGISTRY`) для лёгкого расширения.

## ⚙️ Установка и запуск (разработка)

### Требования

- Python 3.10+
- Windows (используется Microsoft Access Driver и `os.getlogin()`)
- Установленный **Microsoft Access Database Engine** (32/64-бит, в зависимости от разрядности Python)
- Файлы баз данных `.accdb` (основная и сотрудников)

### Установка зависимостей

```bash
git clone <repo-url>
cd DCMDB
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Примерный `requirements.txt`:

```
PyQt6
pandas
pyodbc
openpyxl
```

### Конфигурация

Настройки хранятся в `app/config/app_settings.json` и создаются автоматически при первом запуске (см. `SettingsManager`). Ключевые параметры:

```jsonc
{
  "database": {
    "main_path": "путь/к/DCM-ARCHIVE.accdb",
    "employees_path": "путь/к/List_of_employees.accdb",
    "editable_columns": {
      "default": ["Статус", "Приоритет", "Комментарий"],
      "admin":   ["Статус", "Приоритет", "Комментарий", "Исполнитель", "Срок_выполнения", "Заметка"],
      "tech":    ["Статус", "Приоритет"]
    }
  }
}
```

Пути к базам можно изменить как вручную в JSON, так и через вкладку **Настройки** в самом приложении.

### Запуск

```bash
python main.py
```

## 📦 Сборка и деплой

Приложение собирается в `.exe` через **PyInstaller** и распространяется по гибридной схеме:

1. Мастер-копия и `version.txt` лежат на сетевой шаре.
2. Локальный `launch.bat` у каждого пользователя сравнивает версию на шаре с локальной.
3. При расхождении версий — автоматически копирует обновлённые файлы на локальный диск.
4. Запускает локальный `.exe` (для скорости работы с UI и меньшей нагрузки на сеть).

```bash
pyinstaller --noconfirm --onedir --windowed main.py
```

> Для уменьшения размера `_internal` папки рассматривается использование `--exclude-module` для неиспользуемых модулей Qt6/Python.
